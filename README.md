# Reviva Skin & Surgery

A frontend-only React + Vite website for Reviva Skin & Surgery.

## Structure

```text
client/   React frontend, page content, and Tailwind styles
```

## Run locally

1. Install dependencies:

   ```bash
   npm install
   npm install --prefix client
   ```

2. Start the client:

   ```bash
   npm run dev
   ```

The client runs on `http://localhost:5173`.
